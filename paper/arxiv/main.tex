\begin{abstract}
We introduce \CDC, a small formal substrate and executable toolchain for systems
that combine continuous dynamics, event-triggered balanced-ternary commitments,
delayed angular coupling, local invariants, nested reference frames, and
belief/error minimization. The calculus uses five canonical
primitives---cells, channels, modules, fields, and commits---plus a
bidirectional coherence-delta operator for coupling nested scales and path
endpoints. The artifact includes a canonical native source language
(\texttt{.cdc}), a typed collecting frontend, a stable C ABI, fused native
execution, crash-safe guarded persistence, typed effect receipts,
deterministic build/install/execute lifecycle, non-Python bridge and reducer
runtimes, generated higher-arity bridge codebooks, a finite proof checker, and
Lean/Rocq finite carrier and algebraic mirrors. A frozen Python bootloader is
retained only as an independent CI differential oracle. A separately bounded
Reference-Frame Topological Coherence (RFTC) extension adds six typed forms and
an authenticated local control-plane experiment without promoting classical
software evidence into a quantum or deployed-network claim. The mechanized
layer covers the $n=6$ balanced-ternary walk spectrum, finite algebraic laws,
and double-cover sheet parity; continuous-reduction, hostile-package, and
cross-host obligations remain staged explicitly.
\end{abstract}

\section{Motivation}

Software systems that model embodied agents, mixed-reality worlds, adaptive
interfaces, simulations, and reactive infrastructure often need several regimes
at once: continuous flow, discrete state transitions, delayed influence,
invariants, nested scale, belief updates, and local policy gates. These regimes
are usually split across unrelated tools: dynamical systems, event buses, state
machines, workflow runtimes, neural models, policy engines, and dataflow graphs.

\CDC\ is an attempt to compress these regimes into one executable formal object.
The goal is not to replace every specialized runtime. The goal is to give hybrid
systems one shared semantic spine:
\[
\begin{aligned}
\text{carrier algebra} &\to \text{terms} \to \text{congruence}\\
&\to \text{flow/commit reduction} \to \text{operator algebra}\\
&\to \text{native witnesses}.
\end{aligned}
\]

Related trace-order programs model observation through observer windows over
Markov kernels and treat observer time as local ordered experience rather than a
detached global clock \cite{hoffman2024traces,hoffman2014time}. \CDC\ does not
adopt that ontology. It only preserves the engineering constraint that
observation is a bounded role over a trace, not a privileged external primitive.

\paragraph{Expository order.}
The presentation keeps the formal object, source notation, and native witness
suite close to one another. Definitions are introduced where their native witnesses
first become visible, so the reader can follow the calculus as both a mathematical
specification and a running artifact.

\section{Carrier Algebra}

\begin{definition}[Coherence algebra]
A coherence algebra is a structure
\[
\C = (C,\oplus,\botv,\rot,|\cdot|,\kappa)
\]
where $(C,\oplus,\botv)$ is a commutative monoid, $\rot_\phi:C\to C$ is a circle
action by $\oplus$-automorphisms, $|\cdot|:C\to\mathbb{R}_{\geq 0}$ is an
amplitude seminorm, and $\kappa:C\to[-1,1]$ is a commitment coordinate.
\end{definition}

The standard model specified by the native witness suite is $C=\mathbb{R}^2 \simeq
\mathbb{C}$, $\oplus$ is vector addition, $\botv=0$, $\rot_\phi$ is phase
rotation, and $\kappa(x)$ is the cosine coordinate of $x$ when $x\ne 0$.
For a fixed deadband $\delta\in(0,1)$, define the runtime trit
\[
\tau(x)=
\begin{cases}
+ & \kappa(x)>\delta,\\
- & \kappa(x)<-\delta,\\
0 & \text{otherwise,}
\end{cases}
\]
and the boundary openness
\[
\chi(x)=\max(0,1-|\kappa(x)|/\delta).
\]

\section{Terms}

Fields are generated by five constructors:
\[
F,G ::= 0
  \mid m[\bar v;\bar b]
  \mid F\parcomp G
  \mid p \triangleright \langle w,t,\alpha,L\rangle p'
  \mid m\nest{F} .
\]

Here $m[\bar v;\bar b]$ is a module containing a cell vector $\bar v\in C^n$ and
belief vector $\bar b\in\mathbb{R}^n$; $F\parcomp G$ is parallel composition;
$p\triangleright\langle w,t,\alpha,L\rangle p'$ is a delayed weighted relation
from source path $p$ to destination path $p'$, with angular phase bias $\alpha$
and optional target-line projection $L$; and $m\nest{F}$ is nested field
structure.

Structural congruence makes $(F,\parcomp,0)$ a commutative monoid and treats
channels as an order-free multiset. This is the compositional backbone: parallel
order is not semantic order.

\section{Hybrid Reduction}

Computation is an interleaving of continuous flow and guarded discrete commits.

\paragraph{Flow.}
$F\xrightarrow{d}F'$ evolves phases, amplitudes, beliefs, and plastic weights for
real duration $d\geq 0$ under an afferent-driven vector field. Each incoming
relation reads its source path at delay $t$, rotates that phasor by $\alpha$ into
the destination frame, optionally projects it to target lines $L$, and gates it
by source and target openness before superposition. A future reducer may choose
RK4, Euler, or another realization method, but numerical realization is not the
definition of the calculus.

\paragraph{Commit.}
$F\commit F'$ applies an evented guarded update to a module:
\begin{enumerate}
\item phase cells snap fractionally toward committed poles;
\item a nonnegative prefix-walk invariant is enforced over trits;
\item belief steps toward local evidence;
\item the update is accepted or held with an explicit commit-time status;
\item committed nonzero trits latch persistent poles.
\end{enumerate}

The local objective is
\[
\Phi_m =
\sum_i \left[
\frac{1}{2}\pi(\operatorname{Re}\hat A_i-b_i)^2
+\frac{1}{2}(b_i-b_i^0)^2
-|\hat A_i|\cos(\arg\hat A_i-\theta_i)
\right].
\]

\paragraph{Trace windows and measurement.}
A window is a derived path/line/angle-bounded projection over a field. A trace
records phase-time and event-time through that window without changing dynamics.
A committing measurement is a windowed commit record: it uses the existing
guarded commit, reports a balanced-ternary outcome vector in
$\{-1,0,+1\}^n$, and must not increase $\Phi_m$. Thus observer, participant,
and measurement interface are roles over windows, not new primitive entities.
Trace order is local to the window: smooth phase motion can accumulate with zero
commit events, and different windows can see different event densities over one
field.

\paragraph{Nested reference frames.}
For $m\nest{F}$, \CDC\ couples parent and child by bidirectional
coherence-delta, written $\bidi$: parent context is carried downward and child
coherence contributes afferent evidence upward. Operationally these are the
neutral $\alpha=0$ aggregate relations of the same path-channel operator.
Nonzero $\alpha$ represents angled reference-frame transfer; projected $L$ names
the destination dimensions participating in the relation. Distinct nesting paths
are distinct reference frames.

\begin{claim}[Preservation]
Every accepted guarded commit produces an admissible committed module: the
prefix walk of runtime trits never goes negative. A balance-violating proposal is
held and reported with an explicit reason rather than repaired into state.
\end{claim}

The native witness registry records both the carrier enumeration obligation and
the commit-preservation obligation.

\begin{claim}[Commit soundness]
Commit-time guard soundness is separated from continuous numerical trajectory
error: accepted commits latch only checked proposals, while rejected proposals
hold instead of mutating state. The broader free-energy Lyapunov theorem remains
witnessed for staged guard/subset obligations rather than claimed as a completed
continuous proof.
\end{claim}

\begin{claim}[Local confluence]
Commits on modules with disjoint channel footprints commute.
\end{claim}

\begin{claim}[Flow additivity]
For off-grid split durations in a conforming reducer,
$\xrightarrow{d_1};\xrightarrow{d_2}$ agrees with $\xrightarrow{d_1+d_2}$
within numerical realization tolerance.
\end{claim}

\begin{claim}[Trace-order locality]
Smooth phase-time can flow through a bounded window with zero commit events, and
event order remains local to the observing window rather than a universal tick.
\end{claim}

\begin{claim}[Normal forms]
Committed irreducible localized modules correspond to closed nonnegative walks.
For $n=6$, the saturated localized count is Catalan $C_3=5$ and the crossing-
permitting localized count is $51$.
\end{claim}

Together, the four bridge/carrier/existence/trace invariants, four algebraic
invariants, and five reduction invariants make the 13-key semantic registry
exercised by the canonical frontend and checked differentially against the
frozen bootloader oracle. Framework role contracts are enforced for
completeness, uniqueness, closure, and role-primitive compatibility. The bridge
runtime compiles as C and consumes
\texttt{bridge64.cdc} for lookup, trace-coordinate projection, generated
higher-arity codebook checks, source-declared bridge jobs, and interactive grid
generation. The verified bootstrap bridge is \texttt{n=6}; \texttt{n=9} and
\texttt{n=12} are generated and runtime-checked bridge surfaces, while arbitrary
$n=3k$ generation is queued as a future proof/generator obligation. The native reducer runtime consumes \nolinkurl{native_reducer.cdc}
for flow, commit, nest, compile-IR, IR interpretation, and finite proof jobs,
consumes \nolinkurl{native_surface.cdc} for guard, trace, measure, policy,
bridge, and counter jobs,
and consumes \nolinkurl{council_bridge.cdc} for council deliberation plus
bridge-coordinate source evolution. The same runtime also executes the native
task-framework layer: \nolinkurl{framework_transition.cdc},
\nolinkurl{framework_procedural.cdc}, \nolinkurl{framework_episodic.cdc}, and
\nolinkurl{framework_deliberative.cdc} bind state-change, procedural-memory,
episodic-memory, and decision patterns onto executed kernel jobs under
bootloader-enforced role contracts, and \nolinkurl{framework_loop.cdc} runs
the generic task loop as one continuous composition -- two sense/act/integrate
cycles over one shared state object whose second-cycle expectations are
reachable only through carried state, followed by record, recall, decision,
and enactment jobs over the same source. The same file is the first executable
instance of the Universal Operator: the \texttt{universal} runtime mode holds
one live runtime object through reducer execution, trace/bridge projection,
council decision, closure validation, and enactment, accepting only when
reciprocal angularly biased receptive/radiant causal cones are concurrently
active, a lifted double-cover frame (projected phase modulo $2\pi$, winding
count, $\mathbb{Z}_2$ sheet, accumulated holonomy) returns its projection with
an inverted sheet after one turn and restores both only after $720^{\circ}$,
measured holonomy matches the declaration, and the runtime-computed record
coordinate equals the runtime-computed decision coordinate that is then
enacted. Three negative fixtures hold with precise reasons and create no
evolved output. The operator is derived over flow/commit/nest rather than a
fourth foundational reduction; the finite sheet-parity facts are mechanized in
the Lean and Coq mirrors; the M\"obius/double-cover picture is a topological
realization of the return path, not a physical spinor claim; and a physical
light-cone reading, a continuous holonomy theorem, and any gravity
application remain explicitly queued obligations, since the generic calculus
speaks only of causal cones without a metric or null-propagation constraints.
\texttt{runtime/cdc\_lexer.c}, \texttt{runtime/cdc\_parser.c}, and the
associated AST and diagnostic surfaces form the canonical Grammar-1 frontend.
The older \texttt{runtime/cdc\_source.c} helpers remain only where the
specialized bridge/reducer projections consume them; acceptance, canonical
serialization, and rejection behavior are pinned by differentials before a
legacy path may be deleted.
\texttt{runtime/cdc\_wasm\_exports.c} compile-checks a C ABI for the native
replay JSON path and links a live WASM module when Emscripten is available; live
browser WASM execution remains queued.

\section{Native Source Language}

\CDC\ includes a compact source language, \texttt{.cdc}. A source file declares a
field, modules, channels, reductions, compile jobs, finite proof jobs, counter
programs, and assertions.

\begin{lstlisting}[language={},caption={A small .cdc program.}]
field reducer-field dt=0.125 gain=1.0 deadband=0.5
module council field=reducer-field belief=0.0 prior=0.0
cell council.a module=council theta=1.5707963267948966 omega=0.0
cell council.b module=council theta=0.0 omega=0.0
channel council.a -> council.b weight=0.25 delay=0.0 angle=0.0 lines=1
flow reducer-flow field=reducer-field duration=1.0 expect-theta=council.b:0.25
commit reducer-commit module=council expect-trits=0+- expect-balance=admissible expect-status=accepted expect-reason=none
commit reducer-hold module=holdcase expect-trits=-+0 expect-balance=violated expect-status=held expect-reason=balance-violation
compile reducer-ir source=native_reducer.cdc expect-ops=4
interpret reducer-ir-exec source=native_reducer.cdc expect-ops=4
proof trit-walk-n6 carrier=balanced-ternary arity=6 expect-admissible=267
end
\end{lstlisting}

The canonical C frontend parses and serializes this source into a stable AST.
The native runtime consumes that source for execution, IR emission, IR
interpretation, and finite proof checking. \texttt{cdc\_boot.py} is frozen as a
CI-only independent differential oracle: it is exempt from the zero-Python
kernel floor by name and is not a production execution dependency.

\section{Executable Toolchain and Durable Closure}

The current artifact exposes one \texttt{cdc} driver over the stable ABI.
\texttt{cdc run} executes a parsed program through one live runtime;
\texttt{cdc test --gate} evaluates typed per-job outcomes and treats an
undeclared hold or a run with zero executable jobs as a failed gate. Typed
receipts are constructed by the same code that produces each outcome, so human
report text is not the authority from which effects are inferred.

Durable state is a language form. A \texttt{store} declaration names a
\texttt{cdc\_store}; \texttt{persist ... op=append} invokes the same
balanced-ternary barrier as an in-memory commit. An accepted result may seal a
transaction. A held or violated result has no durable write path. The store
distinguishes a valid unsealed tail from corruption in committed history and
from an I/O fault. Its implementation includes replay identity, byte-level
attestation, atomic snapshot/compact generation transitions, stale-writer
fencing, and process-local plus cross-process serialization.

The package lifecycle reuses that substrate. \texttt{cdc build} emits a
deterministic proof-carrying bundle whose manifest binds grammar and ABI
versions, source digests, corpus identity, artifact digest, and contract
verdict. \texttt{cdc install} captures members once, verifies them, journals
one sealed install transaction, and atomically publishes a complete directory;
kill matrices require either no package or a complete one. \texttt{cdc x}
re-digests every installed member before fused execution. It is
trusted-local-only: verification detects drift and tampering but is not a
sandbox, remote package service, or hostile-code capability boundary.

\section{Reference-Frame Topological Coherence}

The RFTC extension maps the recursive record-closure operation into six typed
source forms: \texttt{frame}, \texttt{reduce}, \texttt{complex},
\texttt{topology}, \texttt{authority}, and \texttt{transport}. A seven-witness
classical crucible independently tests synchronization onset, oriented winding
preservation, hidden microstate granularity, macro/micro recovery, per-packet
admissibility, redundant record closure, and a causal cut.

ABI 1.4 adds a bounded local control-plane experiment. Canonical wire envelopes
bind action, horizon, recipient, payload, and causal state under a
domain-separated keyed BLAKE3 MAC. Scoped versioned authority leases, replay
and causal-order checks, and a serialized supervisor admission boundary guard
exactly-once local transition. Mutation, partition, capacity, forged-ticket,
concurrency, sanitizer, and cross-process-wire counterexamples gate the
construction.

This surface demonstrates shared-key local authenticity and guarded
cross-process admission. It does not demonstrate public-key identity, key
rotation, mTLS, a deployed network, recursive cross-host cells, nonclassical
physical behavior, or quantum advantage.

\section{Universality and Boundaries}

The artifact includes a two-counter construction expressed through generic
instruction modules and commits. This witnesses standard register-machine
expressivity in the Minsky sense. It should be read as an expressivity result,
not as a claim that the current reducer is a production compiler.

Likewise, the neural-dynamics witnesses demonstrate native support for recurrent
continuous dynamics, predictive belief updates, action-style correction, Hebbian
weight adaptation, and nested multiscale feedback. They are not claims of
state-of-the-art biological modeling or training efficiency.

\section{Semantic Spine}

The artifact is organized around one semantic spine rather than parallel
descriptions. \texttt{.cdc} source is parsed into a source AST; execution is
understood against a runtime state tuple; reductions are classified as flow,
commit, or nesting steps; and law checks discharge named invariant records. The
source language, paper, and witness suite are kept close enough to be audited as
projections of the same object. The canonical native frontend has replaced the
bootloader as an execution dependency; the Python file remains by explicit
operator decision as an independent differential oracle. A stronger
self-hosting target would move the reducer, proof checker, witness state, and
trace/window state into native \texttt{.cdc} terms. Deleting the independent
oracle is a separate evidence decision, not an automatic consequence of native
coverage.

This makes the theorem-prover lift narrow and explicit. The finite discrete
layer now has a native C checker plus Lean and Coq source mirrors for the n=6
balanced-ternary walk spectrum: total states, prefix admissibility, localized
closures, saturated walks, and Catalan closures. Lean and Coq also check finite
algebraic laws for gate, interference, and rotation over the finite carrier. The
next proof target is commit-barrier preservation over the same carrier, followed
by continuous-carrier algebra and continuous-flow assumptions around the same
invariant table.

\section{Conclusion}

\CDC\ is a compact executable calculus and native toolchain for hybrid
continuous-discrete coherence. Its contribution is a shared semantic and
durability boundary for systems that must flow continuously, commit
discretely, preserve local invariants, couple nested reference frames
bidirectionally, and retain replayable evidence of each accepted transition.
The implementation closes the path from canonical source through execution,
guarded storage, receipts, and package lifecycle while retaining independent
differentials and falsifying counterexamples. The formal and engineering
results remain intentionally bounded: finite proofs do not imply continuous
theorems, local authenticated transport does not imply a deployed distributed
system, and classical coherence experiments do not imply quantum behavior.

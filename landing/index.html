01 / The proposition

A path is more
than its endpoint.

Two systems can arrive at the same visible position while carrying different histories, internal states and permissions to act.

BiDi keeps those distinctions inside one executable system. Its Coherence-Delta Calculus describes state and relations, applies a small set of reductions, and records the conditions under which a result can become an effect or a further analysis.

Continuous descriptions, finite numerical updates and discrete commitments meet at explicit boundaries. A returned angle, for example, does not by itself establish that the entire system has returned.

02 / Three primitive reductions

I

flow

Move the phase state.

A synchronous finite map updates each phase from the same pre-step state, including the declared frequency and incoming coupling.

flow(d)
II

commit

Make a discrete decision.

Quantize the ordered phase observations to −1, 0 or +1. Accept only when every running prefix sum stays nonnegative.

commit(m)
III

nest

Exchange across levels.

A child's mean trit updates the parent's belief. That updated belief becomes the child's prior under the declared gain.

nest(parent, child)

04 / U1 and U2

Closure, variation,
then the question of return.

Each analysis has its own premises. Completing one step makes its result available without deciding the next.

U1 / Acceptance

Does the guarded path close?

Reciprocal roles, lifted-cover restoration, holonomy, local commits and record agreement determine whether the declared effect may occur.

U2 / Variation

How does that path change?

Differentiate the maps actually executed, in source order and within the accepted discrete itinerary. This produces a path tangent.

U2 / Return

Has the full state returned?

Check every required coordinate and mode, or an explicit complete restoration. Only a verified return authorizes the return operator and spectrum.

The canonical loop / v0.3.0

The cover closes.
The complete state does not.

U1 is accepted and a 13-coordinate path tangent is available. Complete recurrence is held because latch mode, belief, prior and unwrapped phase do not all return. The system consequently emits no canonical-loop multipliers.

A separate calibration fixture explicitly restores a 4π phase advance and its full derivative. That fixture yields the identity return operator I₁₃ with a marginal spectrum. Its success does not change the canonical loop's result.

05 / The wider language

BiDi supplies
the concrete test.

U asks how different mathematical worlds can share a composition discipline. CDC supplies a system whose existing meaning has to survive that move.

BiDi predates U. Its three reductions, source language and native reference remain distinct. U develops a broader substrate; CDC contributes its particular phase maps, balanced-ternary barrier and guarded analysis as a specialization.

The connection is tested through explicit state, numeric and observation contracts. Shared notation alone cannot establish compatibility.
